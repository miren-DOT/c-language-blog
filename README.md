# 个人C语言学习博客
> 使用VitePress搭建的静态技术博客，记录C语言预习笔记

## 项目介绍
本项目基于VitePress搭建静态网页，用于记录C语言的学习笔记。
内容包含：循环结构练习、水仙花数案例、基础C语言代码演示。
项目代码托管在GitHub，并通过GitHub Pages部署上线。

## 项目地址
- GitHub仓库：https://github.com/miren-DOT/c-language-blog
- 在线博客：https://miren-DOT.github.io/c-language-blog/

## 开发环境
- Node.js
- VitePress

## 功能
1. 在线浏览C语言学习笔记
2. 代码片段展示
3. 静态网页，公网可访问
