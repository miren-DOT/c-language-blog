# 工具与部署笔记

## Git

Git 用于管理项目代码版本，保存每一次文件修改记录，支持把代码推送到远程 GitHub 仓库。

## GitHub Actions & GitHub Pages

GitHub Actions 实现 CI/CD 自动化部署：本地提交代码推送至仓库后，自动执行打包，产出静态HTML文件，发布到GitHub Pages，生成公网可访问博客链接。
