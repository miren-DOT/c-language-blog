# C语言循环学习笔记
[[toc]]

## 1. 什么是循环
循环就是**重复执行一段代码**，直到满足停止条件。
C语言常用三种循环：`for`、`while`、`do while`。

## 2. while循环
语法:
```c
while(条件)
{
  // 循环体代码
}
for(初始化; 判断条件; 更新变量)
{
  //循环体代码
}
do
{
  //循环体
}while(条件);
