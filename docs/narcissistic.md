# 水仙花数
## 题目说明
水仙花数是一个三位数，每一位数字的立方相加等于数字本身。
例：153 = 1³ + 5³ + 3³

## 解题思路
1. 取出百位、十位、个位
2. 计算三个数字立方之和
3. 判断立方和是否等于原数字

## C语言代码（无自定义函数，适合初学）
```c
#include <stdio.h>
int main()
{
    int num;
    int a, b, c;
    for(num = 100; num <= 999; num++)
    {
        a = num / 100;        //百位
        b = num /10 %10;      //十位
        c = num %10;          //个位

        if(a*a*a + b*b*b + c*c*c == num)
        {
            printf("%d 是水仙花数\n",num);
        }
    }
    return 0;
}
